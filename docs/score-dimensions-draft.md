# 打分维度重做 · 初稿（待定）

> 2026-11-24。本稿只讨论 `frame-critique` 的维度与权重，不改卡。旧五维（内容与陈述 25／结构骨架 20／对比层次 20／色彩关系 20／完成度 15）是批一至批二凑的，D-01 当时写明「全部书蒸馏完后统一重定义」——现在是那个时点：书已到 14 本，卡已到 8 张。

## 一、旧五维的五个毛病

1. **来源不明**：25/20/20/20/15 没有任何一本书给出，是当时为了能出总分凑的。
2. **维度重叠**：结构骨架、对比层次、色彩关系三者都在判「关系」。同一处问题会被扣两次——主导对比不成立，既扣对比层次又扣色彩关系，总分被双重惩罚。
3. **两张卡没有落点**：包里明明有 `ways-of-seeing`（力的成立）与 `shoot-plan`（光），打分里却没有「力」和「光」的位置。用光失误只能塞进「完成度」，而在 `shoot-plan` 里那是判断项，不是缺陷项。
4. **最不可核对的维度权重最高**：「内容与陈述」占 25%，但它恰恰是不可测量的（情感反应没法复算）。这违反「分数必须与诊断同源」。
5. **没给中式观看留位置**：`chinese-eye` 的判据（单一收束还是游走、虚实承重、气眼）塞进任何一维，都会变成用西方构图标准给中国画式画面打分。

## 二、新方案：六维 + 两项不评分陈述

| 合计 | | 100 | — | | |

**看图的顺序建议**：先看陈述（第一眼落在哪）→ 再看骨架（框与分割）→ 然后力、光、色（三者一起看，因为它们在画面上是同一处）→ 最后放大看完成度。给分的顺序不必照这个，但**每一维必须先说出「看哪里」，再说分**，否则分数没有落点。


**两项写进报告但不计分：**

- **可编排性**（`sequence-edit`）：这张在组里有没有「专有意义」、能不能被同类替换。
- **空间与虚实**（`chinese-eye`）：只在用户明确用中式观看语境时启用，判单一收束还是游走、气眼是否通。

**保留的三条硬规则：** 硬缺陷（焦点不实／抖动／主体被裁／严重欠过曝）总分封顶 60；任两维低于该维 40% 再减 5；只做同批比较，跨批不可比。

## 三、权重为什么是这样

三条排序规则，按顺序套：

- **规则一：可核对性优先。** 能跑脚本或能指认的维度给高权重——骨架（22）与色（20）合计 42，因为它们是唯一能用数值复核的两维。
- **规则二：一票否决要单列，但不能占大分。** 完成度只给 10，因为它判的是「能不能交」，不是「好不好」；用一个封顶（≤60）就够，不必用权重去表达。
- **规则三：判断性维度降权。** 陈述 18（不可量）、力 15（主观度高）、光 15（多数题材光线是给定的，判断空间小于构图与色）。

旧「对比层次 20」被拆掉：明暗跨度部分并入「光」，主导对比部分并入「色」；主导对比若本身就是明暗，记在光、不重复记在色。这一拆解决了旧方案的双重惩罚。

## 五、需要你拍的四件事

1. **接受六维吗？** 比旧方案多一维，报告表会长一行。
2. **「力」与「光」独立成维，还是并回骨架／完成度？** 独立才可核对，但报告要多读两行。
3. **chinese-eye 要不要第二套权重？** 即中式语境下按「骨架 15／虚实承重 15／气眼」重排，其余维度不变。
4. **权重数字。** 18／22／15／15／20／10 是我按上面三条规则推的；你若有偏好（比如光降到 10、色升到 25）我照改。
