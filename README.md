# photo-rx

把 14 本摄影与视觉理论的书，压成一套**能对着一张照片给出判据、量、改动和失效条件**的技能包。

不是修图教程，也不是器材评测。它回答的是：「这张为什么看着不对」「该往哪个方向改」「改到什么程度就该停」。

---

## 一、它做什么

| 你会问 | 它给什么 |
| --- | --- |
| 这张照片哪里不对、怎么改 | 一条主导判断 + 3–5 分项判据 + 2–3 条按代价排序的改动 + 每条改动的失效条件 |
| 颜色怎么调、两色面积怎么配 | 先量事实（面积占比、L 值、色相族、色度峰值），再定主导对比，再分「协调／张力」两条路径 |
| 几点去拍、阴天拍什么、逆光怎么曝 | 光质与光位 → 时段与天气 → 曝光与色彩 → 一张时段表，每条带失效条件 |
| 这批照片留哪几张、怎么排 | 先问用途与名额 → 分堆 → 四类硬理由删 → 定一组对抗关系 → 一句弧的描述 |
| 为什么这张看着别扭、凭什么说这里重 | 说力再说物体、找抵消点与不稳点、判读法是被图式带走还是被画面逼出 |
| 留白怎么留、中式空间怎么拍 | 单点收束还是游走折返 → 哪一远 → 势与质 → 虚实承重 → 气眼 |

**不做**：修图软件操作、器材购买推荐、影像真伪鉴别、色彩管理工程、「好看不好看」的口味争论。

## 二、九个入口

`photo-rx` 是路由层，其余八张是能力卡。第一次使用时全装上，路由会按问题分派。

| 入口 | 一句话 | 什么时候进 |
| --- | --- | --- |
| `photo-rx` | 路由：判问题落在哪条线，单域直达、双域先结构后色彩、三域以上先问主问题 | 一句话里混着几件事，或不知道从哪问 |
| `color-decision` | 色彩关系诊断与取色决策 | 颜色不对劲、要定配色、要统一一组色调 |
| `structure-read` | 画面骨架读取 | 乱、散、挤、平、空；主体放哪、地平线多高、裁到哪 |
| `shoot-plan` | 光线与时段计划 | 几点去拍、阴天拍什么、逆光怎么曝、白平衡要不要校 |
| `cull-select` | 选片：按用途取舍，不按好看排序 | 拍完一批挑不出、只能交五张 |
| `sequence-edit` | 序列编排：色彩弧、减法、专有意义 | 一批已定留片，问顺序、段落与整体色调走向 |
| `ways-of-seeing` | 视看机制：为什么会被看成这样 | 为什么明明对称却不稳、这条规则和那条打架听谁的 |
| `chinese-eye` | 中国观看体系：三远、留白、多角度观照 | 留白、气韵、总想换机位但不知换到哪 |
| `frame-critique` | 单张诊断与六维打分（报告页，西式／中式两套口径） | 这张怎么样、能打几分、差在哪一维、能不能发 |

每张卡的输出都是**固定形状**：主导判断 → 分项判据（成立／勉强／不成立 + 判据）→ 按代价排序的改动 → 失效条件。跨域时先给结构、再给色彩，合成一页；问到三个以上域时先问「你最想先解决哪一个」；同一批既问留哪些又问怎么排时，先 cull-select 再 sequence-edit，合成一页。

**`frame-critique` 的分数口径**（D-10，两套，报告首行必须声明用哪套）：西式 陈述 18／骨架 22／力 15／光 15／色 20／完成度 10；中式（用户谈留白、气韵、三远、虚实或题材为中国画式观看时启用）陈述 12／骨架 18／势与质 20／虚实承重 25／色 15／完成度 10。跨套不可比。每维必须「分 + 判据 + 证据」三件齐，写不出证据的维度标「未测」；有硬缺陷（焦点不实、抖动、主体被裁、严重欠/过曝）总分封顶 60；任两维低于该维 40% 再减 5；只做同批比较，跨批不可比。

**卖片与编排的顺序**：同一批照片既问「留哪些」又问「怎么排」时，路由固定走 cull-select → sequence-edit 的链路，一次答完；两张卡各自保留独立判据（四类硬理由 vs 弧与对抗），不合并。

## 三、知识底座

- **14 本书**：13 本逐页解析（PDF → 块 + 图 + 印刷页号），合计 **3,878 页、约 257 万字、3,919 个图块**；《The Art of Pixar》为整本文字摘录（38 页锚，画册以图为主）。
- **401 条单书主张**（每条带书名、页锚、原文引文、领域、立场）。
- **271 条归一主张**：同一件事在不同书里的说法合并成一条，保留全部出处；单源主张会被标 `single_source`，不许说「多书一致」。
- **12 组对抗（counter）**：两本书在同一问题上立场相反时立一条，写明双方引文、裁决方式（按意图、按层次、按视点、按尺度分岔）、可反向写入条件，运行时按条件分岔而不是折中。

书目：摄影色彩圣经 / Interacting with Color / Interaction of Color / 摄影师的视界 / 光线与用光 / 艺术与视知觉 / 艺术与错觉 / 中国美学史大纲 / 美学散步 / The Art of Pixar / 林泉高致 / 摄影构图与色彩设计 / 观看之道 / 秩序感。

## 五、怎么用

**在 agent 里直接问**（技能已装上就会自动路由）：

- 「这张哪里不对」（附照片）→ 结构 + 色彩双域
- 「这两张选哪个，只能交五张」→ cull-select
- 「下周三下午去海边拍，几点合适」→ shoot-plan
- 「这批照片怎么排」→ sequence-edit

**单张量产**（不依赖 agent 的裸测量）：

```bash
python tools/measure_photo.py <图片路径> --out out/analysis/<名字>
```

一次跑完 12 类量：画幅与 ICC、色相族占比、三分之一区明度与暗部质量、明暗跨度、亮池、色度峰值（窗光/灯）、暖块、暗块、中性锚、最强横纵分割线、参考线距离、边缘吸附、区域抽样点。

产出 `measure.json` + 三张核对图：

- `verify-sheet.jpg`：上半是打了编号框的缩略图，下半是每个框的裁图与实测值 —— **引用任何数值之前先看这张**，确认框没有落错。
- `thirds.jpg`：三分线与 5:8 线叠加。
- `grid.jpg`：10% 网格。

单张约 1–2 秒（1400px），数值可复现。脚本只报事实，不下判断；判断由卡片按事实表给。

## 六、验证做到哪

| 项 | 结果 | 口径 |
| --- | --- | --- |
| 引文可核对 | 401/401 命中标注页，0 条漂移、0 条缺失 | `tools/check_claims.py`，去标点逐字比对 book.md |
| 编译 | 9 个入口，0 error 0 warning | cangjie-skill v2.5.0 |
| 路由盲测 | 176/180 = 97.8%（Wilson 94.4–99.1） | 7 卡各 24 题 + 包级 12 题，另一 agent 盲判；4 条残留失败有意不修（本轮早于 frame-critique 加入） |
| 无技能对照 | 18/24 = 75.0% | 只给 8 个名字、不给描述的路由盲测（同上，早于第 9 卡） |
| 反证闸（该拒则拒） | 30/30（第二轮） | 30 条新用例，一半该 block、一半该 pass |
| 复合意图 | 12/12 | 单域／双域／三域以上／跨图，四档分派 |
| OCR 抽样 | 曼特 20/24 逐字确认；郭熙 15 条有字全部一致 | 视觉模型转写 vs 原文，空转写不计为错 |

**已知缺陷，写在明处：**

1. **权重是推出来的，不是书里给的**：西式 18/22/15/15/20/10 与中式 12/18/20/25/15/10 由「可核对性优先、一票否决单列、判断性维度降权」三条规则推出（D-10），尚未经盲测校准；现在这个总分只在同一批、同一用途、同一口径下可比。文中所有分数都要带这句声明。
2. **新卡未参加盲测**：`frame-critique` 与「先删后排」的链式路由是在最近一轮盲测与反证闸之后加入的，尚未单独跑路由盲测与拒单测试（结构上照既有九张卡的口径写的）。
3. **密排整页 OCR 会空转写**：整页密排文本的裁图会让本地 4B 视觉模型跑 250 秒后返回空串。只对段落级裁图有效，这是工具限制不是原文问题。
4. **页锚有历史偏移**：`arnheim-art` +4、`chinese-aesthetics` +1、`meixue-sanbu` +1，其余为 0；偏移已登记，未整批重校。
5. **引文检查脚本有噪声**：`check_card_quotes.py` 会把标题、自造术语、用户语也当引文，报「未逐字命中」是常态，需人工看。
6. **单张分析仍偏贵**：一次完整诊断约 8–15 次往返（测量 + 核对图 + 卡片输出契约）；固化成 `measure_photo.py` 之前是 45 次。

## 七、加一本书

```bash
# 1 解析（MinerU pipeline）
python tools/parse_books.py --batch N

# 2 建正文与页锚
python tools/build_book_md.py --slug <slug>

# 3 挑代表图版（可选，用于核对书的举例习惯）
python tools/pick_figures.py --slug <slug> --n 40

# 4 按章节切出待读片段，挖主张
python tools/mine_extract.py --slug <slug> --pages <起>-<止> --name <段落名>

# 5 写 claims → 校验 → 并入归一库
python tools/check_claims.py books/<slug>/claims/claims.yaml
python tools/bN_normalize.py

# 6 更新 verified.yaml（书单、证据映射、revision）并编译
python <cangjie>/scripts/cangjie.py compile --bundle .cangjie/capabilities --out out/dist --output pack --yes
```

规矩三条：**只写书里说过的**（每条主张挂原文引文与页锚）；**单源不说多书一致**；**数值只来自脚本**，估的一律写「未测」。

## 八、出处与依赖

- 14 本书均为公开出版物（含中文译本，版本记录在 `verified.yaml` 的 `baseline_tag`）。仓库里只有**引文片段**（用于核对主张是否忠实），不提供全文；`books/*/source/book.md` 是解析产物，仅供本地核对，请勿再分发。
- 运行时依赖：Python 3.14 + numpy + Pillow（`measure_photo.py`）；编译依赖 [cangjie-skill](https://github.com/starryj) v2.5.0。
- 解析依赖 MinerU（pipeline 后端）与本地 Ollama（`qwen3-vl:4b`，仅用于图版描述与 OCR 抽样）。
