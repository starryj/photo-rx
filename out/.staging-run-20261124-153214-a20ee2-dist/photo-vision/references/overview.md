# photo-vision · 书群总览（批一 + 批二 + 批三）

七本书，分成三组来源，覆盖三条判断线加一层解释：**色彩关系**（三本色彩书）、**结构 / 光线**（两本弗里曼）、**视看机制**（阿恩海姆、贡布里希）。

## 一、七本书的定位

| 书 | slug | 立场 | 给什么 | 缺什么 |
|---|---|---|---|---|
| 《摄影色彩圣经》Wignall | color-bible | 规则派 + 实操派 | 具体判词：时段、色温档、滤镜、测光、区域色象征 | 规则多而验证少；器材时代性最强；后期章最快过时 |
| 《Interacting with Color》Horstman | interacting-with-color | 相对派（执行层） | 八个可动手的练习，把「相对性」变成可做的动作 | 是教学法产品，不是观看理论；对「好看」主动弃权 |
| 《Interaction of Color》Albers | interaction-of-color | 相对派（源头） | 立场宣言、边界即度量、数量两维度、等明度难题 | 几乎不谈摄影；反规则也是规则；图版是作品不是证据 |
| 《摄影师的视界》Freeman | freeman-sight | 结构派 | 画幅—分割—元素—关系—纵深—引导的完整骨架，及判据 | 判据建立在纸质观看与单反前提上；几何方法靠教学验证 |
| 《光线与用光》Freeman & Quinn | freeman-light | 技术派 | 光质光位时刻曝光色彩配件的六段可执行流程 | 闪光与影棚是入门级；未讨论 LED；色温表与色彩圣经口径不同 |
| 《艺术与视知觉》Arnheim | arnheim-art | 机制派（格式塔） | 知觉如何建构：力先于物、平衡由重力与方向、简化双向、轮廓≠形状、梯度与重叠、框架是窗口 | 静态单眼实验基础；不谈运动影像与计算摄影；比例是几何式而非像素式 |
| 《艺术与错觉》Gombrich | gombrich-illusion | 机制派（再现心理学） | 图式 + 矫正、制作先于匹配、观看者的本分、心理定向、区别性特征、错觉＝排他性解释 | 以西方写实传统为轴；生活观看与读画可比性他本人留作开放问题；不谈数字后期 |

## 二、三条判断线与一层解释的分工

- **色彩线**（color-bible / interacting-with-color / interaction-of-color）→ `color-decision`：先量事实，再定主导对比（七型），判数量（面积 + 重复），按意图分岔，只改数量与明暗、慎改色相。
- **结构线**（freeman-sight）→ `structure-read`：画幅 → 分割 → 元素 → 关系 → 纵深 → 引导，六段各给判据与一个可数的量。
- **光线线**（freeman-light）→ `shoot-plan`：光质 → 光位 → 时刻 → 天气 → 曝光 → 色彩 → 配件，收成一张时段表。
- **解释层**（arnheim-art / gombrich-illusion）→ `ways-of-seeing`：不产配方，只在「两条规则打架」「判断被质疑」「合规却不好看」时回答为什么。它不替换上面三条线，只做它们卡住时的上游。

**三者的接缝**：结构判断回答「哪里站、怎么框」；光线计划回答「什么时候去、光会怎样」；色彩诊断回答「颜色关系成立吗」。同一张照片三者都可能有问题，按「结构与光决定骨架、色彩决定关系」的顺序串行，最后合成一页结论。

## 三、四个运行时冲突（已裁决，见 counters.yaml）

| id | 冲突 | 出口 | 运行时的做法 |
|---|---|---|---|
| K1 | 色彩和谐是不是客观目标 | both-valid-by-intent / branch | 要交付、要协调 → 走配方；要张力、要当代 → 走数量约束 |
| K5 | 规则能否指导拍摄与后期 | downgrade-side-a / downgrade | 规则是条件判词，跨出条件即无依据；每条必须挂失效条件 |
| K6 | 照片该不该承载再现与表达 | both-valid-by-stage / branch | 分析色彩时暂时屏蔽内容；创作与选片时内容必须进判断 |
| K7 | 照片能否裁决视觉判断 | split-by-measurable / downgrade | 数值以仪器为准、色相以眼睛为准、模型描述不得冒充测量 |

**K7 是本包的口径基石**（与阿尔伯斯 p029 及色彩圣经测光章同时成立）：所有结论必须标明依据来源——脚本测量 / 人眼判断 / 模型描述，三者不可混用。

## 四、覆盖缺口（如实登记）

1. **机制派只到 1960–70 年代**：阿恩海姆与贡布里希覆盖了知觉建构与再现心理学，但**不谈运动影像、多帧合成与算法重构**；这类题材上的机制解释只能降级为推测。吉布森（生态光学）仍未入库。
2. **没有中国观看体系**：郭熙、宗白华、叶朗在批四。散点透视、三远、留白目前只有零散对应（如 C099 书法留白、贡布里希 p016 指出中国不以求逼真为目标）。
3. **编排与选片未建卡**：sequence-edit 与 cull-select 在批五。多张照片的顺序、配对、删选暂只给单张判断。
4. **只有两本有拍摄实践**：色彩圣经与光线与用光。时段、光线、器材类主张大多标 single_source: true，**没有交叉验证**。
5. **色温口径不统一**：freeman-light 记正午与晴天阳光 5200K，色彩圣经记晴天日光 5500K、正午 5000–5500K。两书刻度来源不同，判断时只写区间不写单值。
6. **色彩错觉类图版模型读不出**：本地 4B 只能给结构，不能给「同一张纸片被两种背景切开后看起来是两个颜色」这类判断（校准 C02 失败）。

## 五、材料边界

- 所有原文来自 MinerU pipeline 的 OCR 文本，**引文一律按去标点比对核对**；OCR 有错字（`5oth`、`FRItrH`、`有存在`），引用逐字以脚本为准。
- `pNNN` 是 `book.md` 的页锚，**不是原书页码**；原书页码在 `page-map.tsv`。
- 数值只来自脚本（`measure_general.py`），模型不参与测量。
- 分数与诊断同源（D-01）：每条校正意见必须落到某个维度上；维度表等全部书籍蒸馏完后统一识别。


## 批四增补（2026-11-23）：中国观看线

**两本书的位置**：叶朗《中国美学史大纲》提供画论史的骨架（郭熙的观照论、逸品、意境）；宗白华《美学散步》提供最好用的转述与比较（三远、虚实相生、以大观小、空亭）。两者都不是摄影理论，凡是「该用什么镜头／画幅」的问题原文没有答案，属本包推断。

**第五条判断线 → chinese-eye**：不产出配方，只在用户问「这张为什么空／散／没气」「留白该怎么留」「想做出中国画那种空间」时接手。

**三条新对抗**

| 编号 | 冲突 | 出口 |
|---|---|---|
| K11 | 空间该由一个机位一次定死（单点透视），还是允许视线在画面里游走折返（三远） | branch：建筑／室内／对称走固定视点；山水／街景／要时间感走三远。同一张不得混用。 |
| K12 | 提高视觉强度该把画幅填满，还是留出大片空白 | branch：要覆盖与冲击力走填满；要呼吸与让观者补完走留白。留白前必须先验实部是否够硬。 |
| K13 | 「拍得像／拍得真」是不是评价照片的通用标准 | qualify：逼真降为可选轴，只在用户明确要写实还原时启用；谈意境时不得以「不够真实」扣分。 |

**新边界四条**

1. 三远是山水画程式，用在人像／静物／街拍需要翻译，且人像缺位（只有「人物之在三远」的三种处理）。
2. 「以大观小」在单张照片里几乎做不到，需拼接或移轴，须说明代价。
3. 两本书都没有焦距、画幅、景深、数字后期概念；任何「用 24mm 拍出高远」都是本包推断，必须标注。
4. 宗白华部分论述带 20 世纪上半叶的「中西二分」话语，不可当作文化本质论引用。


## 批五增补（2026-11-23）：序列线

第十本书 **The Art of Pixar: The Complete Color Scripts**（Amid Amidi, Chronicle Books 2011）与其他九本性质不同：它不是理论也不是教程，是一册画集，可用文字只在 p006 的 Foreword、p007 的 Introduction 与 p035 的 The Worlds。但它补上了九本书共同的空白——**没有任何一本回答「一批照片怎么排」**。

**新增第六条判断线**

| 线 | 能力 | 回答什么 | 出处 |
|---|---|---|---|
| 序列线 | sequence-edit | 一批怎么排、弧往哪走、哪张该换位 | Pixar colorscript |
| 序列线（入口） | cull-select | 留哪些、删哪些、为什么删 | Pixar + 弗里曼 + 色彩圣经 |

**两条新对抗**

| 编号 | 冲突 | 出口 |
|---|---|---|
| K14 | 评价一张片子该用单张标准（平衡／焦点／成立）还是整体标准（在序列里的功能） | branch：问「这张哪里不好」走单张；问「这组怎么排／留哪些」走整体，并在回答开头声明用的是哪把尺；两者同时被问到时串行、不得互相抵扣 |
| K15 | 色彩意义是跨作品普遍的，还是作品内部定义的 | branch：问「哪个更抢眼」走知觉层（可用面积／亮度／饱和度解释）；问「这颜色意味着什么」走语义层，先查该作品定义过没有，未定义时给惯例并注明是惯例 |

**新边界五条**

1. 电影有对白与音乐在推，照片序列两者都没有；Pixar 的弧建立在故事已知之上，本包只借「换调色板」这一条，不借叙事。
2. colorscript 是工业流水线产物（美术指导＋灯光＋导演反复迭代数月），个人项目只能借检查项、不能借强度。
3. 全书几乎没有单张分析，故 Pixar 材料不能用于评价单张，只能用于序列与取舍。
4. 文本量极小（25 条主张几乎全部来自一篇导言），抽样偏差大；日后若引入更系统的序列理论（如 Kress & van Leeuwen 的视觉语法）应重校 C164–C176。
5. 选片里「三轮停机」是我的设定，不是原文；书上只给了「必须决定何时停止」这一条原则。


## 批六增补（2026-11-24）：三远改由第一手支撑

第十一本书 **《林泉高致》**（【宋】郭思编，杨伯 编著，中华书局）与前两本中国美学书的性质不同：它是**画论原典**，不是后人转述。此前包里的三远全部来自宗白华 p129 的引文与叶朗的转述，是整个包唯一「引文不由第一手支撑」的地方；现在三远、三大、远近分工、景外意、四时烟岚都有一手出处。

**三处措辞更正（此前皆为转引版，已按原文改）**

| 位置 | 转引版（旧） | 郭熙原文（新） |
|---|---|---|
| 平远之意 | 冲融而缥缥缈缈（宗白华） | 冲融而缥缈（linquan-gaozhi p081） |
| 深远之意 | 深远之色重叠（叶朗） | 深远之意重叠（linquan-gaozhi p081） |
| 观看之目 | 骄侈之目（叶朗） | 矫侈之目（linquan-gaozhi p027） |

**一处归属更正**：「以大观小」不是郭熙的话，出自沈括《梦溪笔谈》评李成「画山上亭馆及楼塔之类皆仰画飞檐」，原话是「李君盖不知以大观小之法」（linquan-gaozhi p084，杨伯引述）。此前包内把两者混为一谈，卡片与术语表已改正；引它时不得挂在郭熙名下。

**新增可量化判据：三大**。「山大于木，木大于人。山不数十百如木之大，则山不大」——比例要按量级算，不按观感算；落地算法是以树叶作共同单位（若干木叶可敌一人之头）换算人、木、山。这是整个中国观看线里唯一可代入数值的比例判据，已进 `chinese-eye` 的 E 段第 3 步。

**四条新边界**

1. 这是**杨伯 编著**本，含注释、译文、点评三件套；本包只把郭熙本文与郭思序当第一手，杨伯的点评算二手，不参与 claims。
2. 附录二《山水赋》（旧题荆浩，与传为王维《山水论》文字基本相同）收作旁证 C186，标注非郭熙本文；「凡画山水，意在笔先」「丈山尺树，寸马豆人」出自此处，不是郭熙。
3. 郭熙是宋代宫廷画家，谈的是绢上的山水；把它用到照片取景上仍是本包推断，凡涉及镜头／画幅的都没有原文答案。
4. 「三远」在北宋并非郭熙首创（杨伯指出宋迪更早以平远知名），郭熙的贡献是把它写成了纲领；引用时宜说「郭熙所述」而非「郭熙发明」。
