1. 美学的局限

从心理学上说，人们可能接收和加工的视觉信息有限。我们看装饰从来不像看画一样仔细，更不要说像读书一样仔细了，装饰能对我们产生影响的话，那也只能是下意识的影响，就像画框一样。研究装饰的学者可以在什么程度上探测人们对装饰的这些变化不定的反应，而又不损害真正使他感兴趣的视觉效果呢？
这个问题不容易回答，但我认为，我们一开始就必须承认这些局限性才能进行我们的研究。我们想要探讨的不是形式的内在特质，即不是视觉图像的恒定特征，而是装饰设计使人产生特定反应的潜力。这一较谦虚的课题的好处在于，它避免了给人洗脑子的缺点。我们不像许多图案设计美学书那样，认为特定的形式或色彩的组合应该或必须用特定的方法来研究。我们知道，我们常常向受试者们问一些启发性的问题，而这些问题不可避免地会影响受试者的回答。怎么不会呢？这些问题是受试者带入图案中来的一部分以往经验。不过他们的回答仍然可能向我们提供一些值得注意的东西。
在早期的一些文章中，我曾提醒人们注意一种用启发式问题分析审美反应的方法—查尔斯·奥斯古德[Charles Osgood]和他的同事们在《意义的测定》[TheMeasurement ofMeaning]中阐述的方法。奥斯古德发现，我们总是愿意回答任何一个关于任何一种经验的问题，不管这一问题多么荒唐，只要它是在我们没准备时突然问的。而且，我们的回答并不随意。比如，如果有人要我们把颜色分暖色和冷色排列出来，我们并不会觉得意外，因为大多数人都认为红色是比蓝色更暖的一种颜色，批评家也采用了暖色这一术语。但是，我们也同样愿意给颜色冠以其他的感官特质，比如，重量、可爱、粗糙、花哨，等等。研究者们可以从这儿开始，进一步探讨颜色的表现特征，比如，温和或强烈、有力或软弱，甚至道德意义上的好或坏。读者可以取其中任何一组对立，将图129中的图案按七等分法进行分类，比如可以分成中间、一般、较暖、最暖、不太暖、较不暖、最不暖。当然，如果就此得出结论，认为对颜色的这种反应总是人们经验中的一部分，那是令人误解的，因为其实它们并不是我们经验中的一部分，是奥斯古德的研究方法使人产生了这种经验。这种方法所探索的是颜色的潜在意义，而不是经验意义。它其实是在力图确定一些能为人接受的比喻，用以描述某些特定的反应。我认为，这就是奥斯古德美学研究的价值所在，因为我们都知道，除用比喻外，没有什么别的方法可以表达审美反应。看看那一长串用来区分葡萄酒的产地和风味的细微差别的牌子，或那些用来区分不同种类的香水的商标，看看批评家用的那些常常使人觉得夸夸其谈、胡说八道的词汇，我们就会明白审美反应是无法描述的。当然，如果就使用的词汇而论，那么批评家们的词汇确属胡说八道，但如果把它们看成比喻，那么对那些能够用自己的经验对这些词汇进行验证的人来说，这些词汇便常是可以接受的了。

2. 不安与平静
欧文·琼斯把他的装饰美学建立在“平静”的理论上。从某种意义上来说，这个词只能是个比喻，因为设计既不会动，也就无所谓“静”。然而我们出于本能知道平静与不安的设计是什么意思。我们怎么会有这种反应呢？通过内省我们知道，如果某个设计使我们感到“被牵引”，我们称它为“不安”。也许最不安的感觉是由不规则的排列或时明时灭的灯光造成的但由于种种原因，我们不能忽视这种灯光，比如当它们被用作战斗信号时。这种排列或闪光可能会加重注意力的负担，使我们不知该往哪里看好，而只是觉得心神不宁，毫无办法。很容易想象这种情景怎样才能变得更好或变得更糟：加强灯光会使信号变得更显眼，在不规则的排列中加进色彩对照会使排列显得更加混乱；另一方面，如果我们掌握了灯光隐现的节奏并且形成了确切的预期，知道我们只需要注意意外的闪现，我们就不会受这灯光的干扰。前一种可能性即加强灯光或色彩对照触犯了我们的秩序感，后一种可能性则适应了我们的秩序感。
我选了一个初始例子，其中的不安是真正的不安，而不是比喻意义上的不安，因为我相信，这些运动的效果在原则上与静止排列的效果没有区别。这一点是由上一章讨论过的视觉仪的本质决定的。眼睛的结构使我们在某一特定的时候只能将视觉焦点集中在一个有限的区域内，如果要看更广的地方就得移动眼睛。如果有许多信号同时在眼前出现，我们会不知先看哪个好，这又会使我们觉得受到了牵引。眼睛得不到停落点，因而得不到宁静[图130a]。
爱整洁的人可以很容易消除这种不安的效果一图中有10个圆圈和10个三角形，只要把它们按一定的规则整理好，混乱马上就消失了。格式塔心理学庄严的大厦就建立在这一基本原理之上。正因为如此，我不得不再解释一遍本书的重点与格式塔心理学所强调的有什么不同。为了与上一章保持一致，我首先得说到延续。整齐的安排具有较多的延续和较少的中断或者说较少的视觉显著点。所以格式塔心理学强调的是对秩序的知觉，而我要大家注意的则是对非秩序的反应。这话听起来好像是在玩弄文字游戏，但是，我相信，不同的强调会得出不同的结果。以“掩蔽效果”[effect ofmasking]为例。这一效果在格式塔学派中占有一席地位。鲁道夫·阿恩海姆在他的《艺术与视知觉》[Art and Visual Perception]中认为，在图131之类的图形中，秩序战胜了经验。因为几乎没人会注意图中包含了一个“4”字。他无疑是对的。但是，没有这些明显的中断[图131]我们怎么可能认出这个“4”呢？如果我们在看图时得检查每一条延续线看看其中有没有包含其他的线条，那我们的日子就难过了。我们已经说过，眼睛是不会这样看图形的，它总是被包含最大信息的点所吸引。这些最大信息量的点在不安的图形中比在秩序图形中要多，正因为如此，不安图形要求更多的注意力。

为时间图案想象出这样一种机械装置比为空间图案想象这种装置要容易些—实际上，在讨论这种形式时，我设想的“中断监测仪”几乎不属于纯粹的科幻小说的领域。由于对生物节奏的监测在医学上是必不可少的，所以有人发明了一种记录病人心跳的仪器，现在这种仪器已开始运用于一些医院的加护病房。医生如果要看24小时的心电图记录，那得花很多时间，因此，可以给机器发出一种指令，让它只记下不合节奏的心跳。不管这种魔术般的机器的制造形式是多么精确，它毕竟得根据一种调谐装置的原理来制作，这种装置能与正常的脉搏跳动的节奏保持一致，但是，一日出现了异常的节奏一即当装置本身的节奏与病人脉搏的节奏不合拍时，它马上会警觉起来。这种装置必须与本书导论中说的推测相一致。我在导论中强调，有机体需要产生一些规则的序列以帮助探测不规则的秩序。我举了一些例子来说明这一点，这些例子包括某些鱼类发出的电脉冲和骑马者作“预先匹配”的能力。骑马者会习惯地与他坐骑的节奏保持着一致，他只需要注意预料之外的颠簸或变化。
从时间形态上来说，不难想象这种装置该如何设计：这一装置得储存着一系列可供选择的节奏和速度，就像舞蹈演员可以根据不同的音乐调整舞蹈的速度一样。最简单的节奏或速度如果长时间地延续而不出现中断，那它用不了多久就会把我们送入梦乡。这种节奏可以产生“平静”，也可以产生“厌烦”。而最复杂的节奏当然应该被称为“不安的”了。

要想建立时间图案的知觉和空间图案的知觉的类比，我们得设想出一个与节奏仓库相应的图形仓库。这样，我们的“中断监测仪”就必须产生出一系列的图形，并用正在输入的刺激对这些图形进行检验。为了与刚才的讨论相一致，我们可以把这些图形称为“样板”[templets]，虽然它们不可能是很固定的图形，而只可能是一些用以扫描环境的波浪式的易变图形。在我看来，格式塔心理学派的许多理论比如上一章提到的“趋合”理论和本章讨论的“掩蔽”理论，只要稍加修改，就能与这种假设相适应。
我们都知道，大脑能够本能地产生，而且也确实产生了比这复杂得多的视觉图形。我们除非处于变态的状况，否则一般很难看见这些图形。我指的是那些使人头晕目眩，而有时又是很美的图形。在脑子出现幻觉时，这些图形就会干扰我们的视觉。致幻药物也常常能使人产生这种图形—装饰中的所谓“致幻”式样[psychedelic fashions]就是从这种图形中得到的启发。有人认为，这种摇摆不定的幻象一直潜藏于大脑中，但通常都被有意识的知觉活动压抑着。从这些病态的表现形式中寻找出一种不受活跃的秩序感控制的效果，将是一件有诱惑力的事。这些幻象是否可以与“中断监测仪”所必须具备的“样板”相类比？在什么方面可以类比？现在还很难说。
这些样板如何才能成为有助于时间上“预先匹配”的内在节奏的对应物？在解释这个问题时，我们无须依靠这些漫无边际的假设。我们已经证明，视觉系统适合于空间规则的探测，不管这种探测是怎样完成的。一排间隔相等的小圆点，即使不位于视觉焦点，并且是在有许多视觉“杂音”的情况下（也就是说在周围有许多分布不规则的圆点的情况下），仍然可以被眼睛发觉。我们可以根据不同的难度对这种探测活动进行分类，直线排列的圆点比曲线排列或棱形排列的圆点更容易被发觉；间隔规则的圆点比间隔不规则的圆点更容易被发觉，这一点可以被图案设计的学者作为证实简单原理的最好例证。我们已经说过，这种简单可以被认为是一种冗余度。一排规则排列的圆点，一旦得到确定和证实，就被认为会一直重复下去，而不会出现新的变化，一组图形越受具体规则的束缚，重新填补图中消失的成分所需要的信息就越少。
[124]
心理学家W.R. 加纳[W.R. Garner]动用这种思想倾向来证明，格式塔理论认为“好”的图形可以从数学上定义为“规则系统中小的子集的成员”。他的分析可能有些武断或人为的成分，但这没关系，这里最重要的是这样一个明显的事实：最规则的形式最容易描述，也最容易产生。要描述一个圆，只需要一个单位一半径。不管你怎么变，半径总是半径。而一块乱石就不可能详尽地描述，也没有与之相匹配的“样板”。
尽管要给“简单”下个万全的定义是件难事，但是，有一点却很清楚：要相信秩序感的存在就必须先假设出一种关于简单和关于复杂的标准。“中断监测仪”不仅会根据逐级复杂的顺序来监测环境，就像“样板”已经事先被这样安排好了似的，而且监测的准确性也将随着监测仪在当时所根据的标准的变化而变化。总的来说，监测仪对图形的扫描就像绘图员绘图一样，先粗粗地画出主要轮廓，然后再填入细节和修改细节[图126]。

3. 平衡与不稳定
在我们的研究领域，有一种视觉效果显然占有特殊的地位，因而也必须成为任何解释性假设的一个重要的测试实例我指的是双边对称以及由此而自发产生的“平衡”感。如果说重复（比如S.O.S.，S.O.S）是一种有冗余度的形式，那么对称显然就是一种特殊的形式—它把中心轴一边的任何安排反映到另一边。但是我们会问，我们的知觉系统为什么会喜欢这种颠倒了的序列？从印刷符号的安排中可以很清楚地看出，我们的知觉系统确实喜欢这种序列。比如，下列由字母“○”和括号组成的秩序就是人们所喜爱的：（(((((((((((((((($( { \bf \nabla } ( \mathrm { { \ O } } ( \mathrm { { O \Lambda } } ) _ { \circ }$ 用一点儿时间，我们就可以看出这种逐次减少括号数目的规则；其中的冗余度也不难发现。但是，如果我们不是重复这一序列而是将它颠倒，那么立刻就会出现一种规律性的回文：((((((((()○)))))))。用几何学术语来说，“平移”比“反射”更难看出。
如果我们还记得“中断监测仪”的偏好，我们就会对这种效应有准备了。在双边对称图形中，中心轴必须是一种“吸引眼睛的磁铁”，因为从定义上说，它是序列中唯一没重复的部分。因此，假想的“中断监测仪”不会“被牵引”，而是会悬于两种相等的吸引力之间，被锁于最大信息点之上。如果利用这一有利点来对简单进行测定，那就一定能够建立起近似成分[proximal elements]的冗余度，因为不管中断监测仪移向中心轴的左边还是右边，它都将得到同样的信息序列。一旦中断监测仪形成了“这种冗余度贯穿两边”的假设，边缘视觉马上会证实这种假设。
中断监测仪能够这么自信地对付中心轴两边的信息，这实际上表明，对称看上去能够扩展我们的视域。让我们将一座富丽的但设计成两边不对称的巴洛克建筑与一座对称的巴洛克建筑作比较[图136a、图136b]。在后一建筑中，我们会觉得无需对每个成分逐一细看就可以观察到视域中心点两边许多互为镜像的特征。建筑的比例增大，这一效果也相应增大。上一章我们讨论了在规则建筑中定向的经验。因此，当建筑师们身手不凡，将一座结构复杂的建筑物或拱顶长廊设计成对称形式，从而产生一种视域开阔的效果时，我们对此不能不由衷赞叹[图137]！
同时，边缘视觉在双边冗余度的整体印象的形成中所起的作用也有助于解释为什么人们不太注意对称形式中微小的偏差，除非他是有意识地在寻找偏差[图138]。大家知道，只要人的五官没有特别出格的地方，我们便不太会注意人脸两边的不对称。只有当别人提醒我们注意时，我们才会觉得无法忽视它们。

正因为我们能容忍对称形式中微小的偏差，罗斯金反对完美的呼吁才会使我们产生同感。完美显得“死板”，因为它有过量的冗余度。如果我们的预期在任何时候都得到证实，中断监测仪没有受到任何震动，我们就会感到单调。
研究视觉效果的人往往很认真地看待比喻，这是对的。因为这些比喻多少总能向我们提示一些对经验进行分类的方法。对称和平衡的等同就是一例。比如，如果把重量和体积相等的东西放在天平的两端「图139]，这种对称同平衡的等同就很明显地表现出来。我们确信天平上的安排是极稳定的，并把这种自信转移到对任何对称设计的观赏中去。然而不管是在机械中还是在设计中，平衡并非一定要依靠对称。双边对称在知觉反应中能占据特殊的地位，一定还会有其他的原因。我认为，仅仅用静止的图形来分析知觉效果是错误的。知觉系统必须能适应处于运动中的有机体的需要，因而“中断监测仪”也必须能适应这种需要。吉布森正是在这一领域中对知觉研究做出了根本的变革，他提醒人们注意视觉系统是怎样引导着运动中的人类通过环境中的变化：如果我们在平坦的道路上开车或步行走向一个物体并把眼睛盯住这一目标，我们不仅会看到它的体积在逐渐增大，而且还能感觉到这个物体的四周在我们眼前以一种规则的形式摆动着，出现一种吉布森所谓的“全景流动”[panoramicflow]。这时候，如果流动表现出不对称，那要么是因为我们偏离了目标，必须调整方向，要么是道路不够平坦。换句话说，边缘视觉中对称图案的“平衡”也包含于监测我们本身的平衡和运动这一基本的经验之中。
这些观察非常符合下面这一理论：要达到对称设计的“平衡”，必须要有一个坚固的框架或另一种孤立这种构形的手段，尤其要注意的是，对一个对称作任何程度上的重复都将威胁着。这一对称的平静感，因为重复破坏了对称轴的单一性。ATA这个序列是对称的，但如果重复这[130]一对称，把它变成ATAATAATAATA，就会产生TAAT和AATAA等新的对称，这些向两边延伸着的对称相互竞争，破坏了原来那个单一对称的平静[图140]。多种不同的“样板”放在一起也会出现这种效果，从而会使眼睛的探索无法得到成功的结果。

在测试简单性时，我们的监测仪用它的“样板”对带有冗余度的重复序列进行了检验。但是，在由相同成分组成的冗余度非常高的设计中，却没有一处可以使“中断监测仪”容易“落脚”的地方。在这种设计面前，监测仪变得游移不定。如果我们想数一系列视觉特征相同的成分，我们总喜欢用手指一个一个地点，因为这些成分“太游移”，靠肉眼无法计算，只要我们稍不留神，就不知数到哪里。场面越大，其中相同的视觉特征就越难以捉摸，因而越给人一种不安的主观感觉。这些相同的视觉特征会在眼前不停地变动，产生出无数不同的解释，就像在

德国神秘主义者和幽默诗人克里斯蒂安·莫根斯特恩[Christian Morgenstern]写过一首小诗，说的是当我们试图对抗延续的牵引时，比如在凝视着画有花卉的壁纸之类的重复图案并把它看成一盘想象中的棋时将会发生什么情况。诗中说：
我是壁纸上一朵精巧小花，
重复出现，无边无际；
我不在五月的月光下开放，
而布满在四周的墙壁上。
无论你怎么看也不能把我看透，
你只能看到我的一小部分；
如果你进了我的迷魂阵，
伙伴儿，那么定会眼花头昏。
使看壁纸的人头昏眼花的并不是重复的花卉图案，而是他那种想用意想不到的方法读解图案的无效尝试。如果他想盯着“迷魂阵”序列中的纹样一个个看下去，他马上就会搞不清自己刚才看了哪一朵花，除非他不怕把壁纸弄脏，在每一朵花上作个记号。即便这样，这一排“迷魂阵”纹样看上去仍然会显得不安，然而它作为壁纸图案总还是可以的。
就像所有的心理机制[psychological mechanism]一样，眼睛被迫沿着固定的、有冗余度的重复线运动。这一点也可以被设计者用来产生对比效果。他可以利用这一机制来加强一种读解，或用一种最不安的办法来扰乱我们的知觉。前一种做法在格式塔心理学家沃尔夫冈·梅茨格的《视觉原理》一书中得到了极好的说明。梅茨格画了两个结构相同，但中止边不同的图案[图143]。在边缘出现星形的图案中，所有的星状图都显得突出；在方格出现在边缘的图案中，整个图案看上去就由方格统治着。
这儿，我们再次看到了这样一种倾向：我们看图时是从外向里看的。正因为这样，我们才能很快看出图144中的两幅图其实是相同的（这两幅图选自19世纪一本法国的装饰手册），只不过有一幅是斜放的罢了。正如人们所预料的那样，图案的边缘最能表现图案特征的部分。在垂直线中断的图中，垂直线就特别突出，而在斜线中断的图案中，我们注意到的只是与边缘平行的交叉十字轴。

霍格思首先提出，“美的线条波纹线”给人的快感最终来源于人的探索心理和人的眼睛。“旋涡线同时向不同的方向波动和蔓延，引导着眼睛愉快地沿着线条的不同延续而转动，如果我可以用延续这个词的话。这些以不同的形式弯曲着的延续中可能包含着（虽然它只是一根单线）多种不同的内容。”
尽管我们已不再把视觉追踪归结于眼睛的运动，我们也无需对霍格思的理论加以驳斥。不管什么是快感的最终来源，大多数观察者都会发现，波纹线比直线更容易表现运动[图149]。这种印象很可能产生于几种因素的汇合。其中之一是当图形与基底完全平衡时图案会表现出一种波动。如果要在波纹线中寻找相同点，我们会发现，其中的每一个起伏都与下一个起伏相对应。确实，在比较“波动轴”上这些互为镜像的形式时，我们得把我们的读解一次又一次地从隆起的图形转向凹下的图形。一种读解中的“图形”在另一种读解中变成了“基底”。但是，波纹线中没有真正的中断或边缘能够帮助我们形成任何一种固定的读解，“中断监测仪”不会像看极其不安的图案那样受到牵引，但它也不太可能安静下来。
我们必须牢记，如果想象中的“中断监测仪”设计出来只是为了在静止的环境中运转或工作，那么它将远远不能和真正的“中断监测仪”相类比。人类世界在不断地运动，中断监测仪也必须能适应于追踪和预测我们本身的运动以及与我们相互作用的物体的运动所引起的变化。换句话说，“这儿是个波纹”这一信息应该使人建立起一种对运动的预期，就像我们看见一个不平衡的图形就会产生“这东西马上会掉下来”的感觉一样。我们是天生就具有这种反应的意向，还是得靠假想的“中断监测仪”组合经验的各种结果之后才能形成这种反应，这是个没有什么意义的问题。
这一点同样适应于我们从放射线图150中得来的印象。许多人会把太阳图形中的黑色线条看成向外四射的光芒。毫无疑问，联想和学习在这种反应的形成中起了作用。但是，就像在看其他的对称图形一样，我们不应该忽视我们本身运动的作用。这种外射与我们走近中间那个圆盘时所预期的效果相一致。将线条与圆盘分开，放射的效果会更加强烈，因为这样一来线条看上去像是在空中翱翔。但是，如果在放射线外加上一个圆圈，放射的效果就会消失，因为圆圈把这些线条变成了车轮上的轮辐。

5. 从形式到意义
我曾试图把几何秩序的知觉和一般事物的知觉区分开来，现在我们应该越来越清楚地看到，这两者永远不能明确区分。比如，我们很难决定装饰设计中最常见的一种纹样一交织纹样到底应该归属于哪类。这种纹样不可能有明确的归类，因为它是一种由打辫、打结或编织的方法做成的完整的实体。但它也常常在三维窗格或浮雕以及平面设计中被用作虚饰。在形式知觉方面，使人感兴趣的不是产生交织纹样的各种媒介的确切区别，而是交织的部分在何种程度上影响了人们对形式和线条的解释。这里，又是“延续的假设”在这种普遍的效应中起着决定性的作用。以中世纪德意志教堂中瓷砖地面上简单的交织长方形图案为例「图156，对这种图作具体描述并不太难，然而尽管这样，我们还是不顾理智地把它看成一种三维空间图案。换句话说，由于受到延续和简单律的牵引，我们把它看成了由交叉的条带组成的图案。虽然没有任何迹象表明实体条带的存在，但是暗示着的条带轮廓使我们不由自主地得出了这种解释。如果设计者想要清楚地说明多义性的图形，或使一个不安的构形变得平静，最好的办法是求助于三维空间。克里斯蒂以令人信服的例子证明，虚幻的交织可以使我们更容易领会形式的系统并缩小其不稳定性。我们知道交织图案是怎么组成的，它是怎样交织在一起的以及如何解开它[图157]。

[142] 6. 色彩
在分析视觉效果时如果只限于几何形式而不考虑色彩，那将是一大局限。视觉相互作用的心理法则就是在色彩领域中首先得到了严格的科学分析。谢弗鲁尔发现“同时对比法则”[laws of simultaneous contrast]的故事已广为人知，不过再说一遍也还耐听。谢弗鲁尔是个化学家，所以他被任命为皇家哥比林挂毯制造公司印染车间的总监。上任不久，他遇到了许多预想不到的困难。有人对车间的某些颜料提出了抱怨，他们发现有些颜色太差。可实际上用在被抱怨的挂毯上的染色羊毛和用在别的挂毯上的完全一样。谢弗鲁尔通过调查终于发现：“黑色挂毯之所以缺乏生气是因为邻色的原因，也就是说是由于色彩对照造成的。”在1828年作的一次讲座中他宣布了这一发现。然后，他又以毕生精力扩展和完善他的发现。这一发现对画家们也有很大的影响。他在自己写的一本书的开头概括了色彩对照法则：“当眼睛同时看到两种邻近的颜色时，这两种颜色在光学结构和色调的高低上都会尽量显得不相同。”(见其书第二章）用我们的话说就是：“中断监测仪”倾向于夸张，由于它不喜欢不确定性，所以它尽量突出不同点。但这只是对颜色变化的一种反应。我在《艺术与错觉》中讨论的“扩散效应”[spreading effect]表明了另一种对色彩组合的更整体性的反应，在这种反应中，我们把对个别色彩的不同感觉转移到整个图案上。谢弗鲁尔在他那本插图丰富的书中[彩图9]以充分的理由强调，他的发现不应该被过分简单化。色彩相互作用这一领域充满着使人惊奇的效果，可惜的是由于技术上的限制，现在还难以证明这些效果。证明这些效果所需的彩色图片如要达到一定的尺寸、数量和保真度就得付出不合算的代价。在第三章中我们已经看到，对数学家来说，色彩的干涉意味着减少了几何图案中存在的纯形式关系。因此，可以在图案中只用一种颜色以强调现存的秩序，也可以使用各种色彩的组合以破坏现存的秩序。但不管怎样，单一色彩图案中的相同点比多色彩图案中的要多，因此，单一色彩图案中相同的成分的轴也更多。由此我们可以很容易看到：颜色可以用来稳定棋盘图中不安的颤动，就像出人意料的色彩对照能够破坏对称设计中的平衡一样。

7. 再现
在本章讨论色彩问题有些离题，因为本章考虑的是纯形式的效果。我们得记住，很少装饰风格是不带再现成分的，或者再现植物和动物，或者再现人和工具。再现意义的引进提出了完全不同的知觉问题，这一点还有待于证明。这种不同来源于知觉仪的两重性一它的秩序感和它的意义感。秩序感可以使我们在时空中找到刺激物的位置；意义感可以使我们从生存的角度对刺激做出反应。有机体必须找到哪些是可与他为伍者，哪些是他的敌人，哪些是食物的来源，哪些是危险的东西。如果说这方面的认识能力只是对他的生存大有益处，那么焦点视觉则是他的生存所必需的。因此，看着一件东西与扫描环境寻找秩序是不同的。如果我们遇见一种既可能是敌人也可以是朋友的动物，我们就必须弄清它的头与尾一“头尾”在这里完全是字面上的意思。一条波纹线和一条蛇可大不一样如果是条蛇，我们就得注意找出哪儿是蛇头，哪里是蛇尾[图162]。

我说过，即使我们对与波纹形式相关的运动的残留预测也可能会影响我们对波纹图案的反应。但波纹线没有空间方向，也没有可确定的尺寸和体积，而蛇却有。因此，我们对图案做出怎样的解释，将产生广泛的影响。把波纹线解释成山、水或飘动的绢带的方法可称为“具体化”的方法，把它看成一条蛇则是“生命化”的方法。具体化和生命化都可以赋予这条波纹线一种新的“存在”，甚至一种空间的光环。这两种方法不受写实主义成分多少的影响，但它们的成功至少得取决于我们所说的“观者的本分”和艺术家描绘现实的愿望。一旦我们看出了一只古埃及前王朝时代[pre-Dynastic]坛子上的图式化鸵鸟[图163]，这些鸵鸟就开始在坛子四周奔跑了。更有甚者，我们还可以由一种读解想到另一种读解。我们可以很容易认出，突尼斯的戈夫萨[Gafsa]地毯[图164]中的边纹图案是一排骆驼，一排立正的士兵和游动于运河中的鱼（鱼稍难辨认些）。认知决定着方向、比例及其潜在的运动。把一个形状看成骆驼就意味着要寻找骆驼的特征，比如骆驼的头和脚。组成骆驼纹样的那些部分将自动地变得紧凑起来，而其余的部分便变成了“基底”或“填补”，或者说我们将一直把这些其余的部分看成背景，直到有人提醒我们，这些被我们认为无意义的形象也有再现功能。
这样一来，形成条件和表现技巧的成分，不但可以影响我们对所有复杂形式的读解，而且还能决定我们对再现纹样的反应。能够说明这一效应的最好例子是哲学家在讨论视觉解释或称“看作”时喜欢用的“鸭一兔变形”[图165]。我们可以取一个与此图相似的墨迹，先把它当成各种不同的图案，然后用“鸭一兔”取代它。我们也可以把“鸭一兔”看作一种系列纹样，然后再注意一下当我们从一种读解转变到另一种读解时会发生什么情况。两种读解都会导致新的方向感：所有的鸭都向左看，所有的兔都向右看。困难—至少我认为困难的是要在中间变换读解，把它交替看成兔和鸭的图案。这一困难证实了我们寻找冗余度的扫描在秩序知觉中的作用。我们不会把每一个单个纹样分开来读解，而只会去确定它们的同一性。把鸭一兔图稍做变化，让鸭嘴对鸭嘴，兔嘴对兔嘴，使得兔子都相互向中心轴靠拢，鸭子都向中心轴偏开，使整个图案随着我们的视焦点的移动而稍微扩大或缩小，这是件很有意义的事。毫无疑问，用这种图案做的壁纸比用克里斯蒂安·莫根斯特恩警告过的那种花卉图案做的壁纸更会使人恼火。不管怎么样，“鸭一兔”图会使我们相信，秩序和意义的相互作用具有复杂的力量。设计者希望怎样利用这些力量将由各种其他因素决定一其中最主要的因素就是图案的目的。正因为这样，对知觉效果的分析才不足以构成审美的标准。即使有人能比本章更进一步分析知觉效果，这一分析最多也只能解释设计者可以运用的方法，而这些方法的运用还得取决于设计者的文化和传统对他的创作活动的作用。

8. 形式与目的
我常说，“形式跟随功能”这一建筑理论也可以成为研究其他艺术的史学家的指导方针。本书的目的不是对这一理论进行论证，然而，读者眼前碰巧就能看到知觉理论的一种运用形式，我指的是排版工艺的文字安排形式。我们知道，当我们在读一页熟悉的文字时，眼睛总是在飞快地移动着，而且还不时运用已有的知识、靠最少的启示来填补眼睛跳过的熟悉单词。秩序感与这种填补过程有关，意义感也同样与它有关。单词被排成了行，行又组成了段落。一篇文章的排版格式对我们汲取其中意义的难易程度有着极大的影响。
在德语及其同语系的其他语言中有一个很有用的词，可以用来描述印刷工艺者要想达到的[146]这种效果，这个词是“übersichtlich”。从字面上来说，它的意思是“一目了然的、明显的”。可碰巧的是，“über-sicht”的英语同源词却是“oversight”[失察、忽略]，它的意思几乎与德语完全相反。这是一个有趣的心理学现象。也许德语意思和英语意思是一枚硬币的正反面。我们还记得，“延续的探测”几乎是自动的，因而不费什么注意力。然而这种探测虽然能导致注意力的松弛，但也带来了危险。在看一排杂乱的字母时，我们不太容易“忽略”其中的印刷错误。显然，排印工作者像其他艺术家一样，必须使他的版面格式适应于“中断监测仪”的特性。词与词的间隔、段落的安排、用大写字母或不同的字形表示强调等手段都证明，延续的间断有着突出重点和吸引注意力的作用。不同的文化传统对这些排版手段做出了不同的反应。海报和报纸上的大标题在很远的地方就会开始召唤我们的注意力。有时它们召唤的声音过大，我们反而不予理睬。而《古兰经》上就不需要这些大标题，因为它是为那些也许已经能背得出经书的读者印的。更引人注目的是一种各国文字中都存在的而且显然是在不同的文化中单独发展起来的现象—我指的是一行字的排列方式。不管它是从左到右还是从右到左，或左右交替排列，也不管它是从上到下或是偶然排成螺旋状，每一种正规手写体总是用最简单的方法排列，以便于读者连续地阅读，吸取其中的意思。在这儿，秩序和意义相互作用着。但是，过分的秩序将影响意义的知觉，这一点排字工人和校勘者都知道。如果同一个词或同一排字母上下连续几行对齐出现在同一页上，那么便会出现一种“对立延续”，这种对立延续将会影响眼睛的换行并产生混乱的效果。研究中世纪版本的学者常常发现，有些段落文不对题，毫无意义，这是由于抄写的人看错了行而造成的。

有些文字不像书法或印刷体那样，可以很容易写成规则的几何形，它借用联结字体或草写将字母连成单词。在读这种文字时得注意，不要把上下行搞混，造成错误延续。在这种情况下，我们的自动的中断监测仪就会停止工作，因为没有足够的指令让它跟踪意义而不是形式。不过总的来说，各种书写形式的发展都极好地说明了本书所提倡的知觉方法。秩序感能解释一行字和一页字的安排，也使眼睛能够轻而易举地找到规则中的微小变异一这些变异组成了区分单词、标点和段落的明显特征，这些单词反过来又会被装饰欲望改变形状。至于装饰欲望是如何改变它们的，我们将另外讨论。
装饰研究的困难，同时又是最吸引人之处在于：这种研究关心的是一种几乎没有任何明显的作用或功能的活动。在装饰中，人们可以尽力发挥自己的秩序感，产生任何形式的简单图案或复杂图案。我们不能强行规定，设计者应该设计平静的图案还是不安的图案。西方人一般喜欢对称形式，而远东则喜欢微妙的平衡形式。有些装饰风格，比如埃及或古希腊的装饰图案，尽管复杂多变，但仍然能给人一种清晰的印象。其他的装饰图案中却包含着好几种解释，因而对寻求的眼睛产生一种不稳定感。这种不稳定的效果给希腊化时期的镶嵌铺道增添了魅力，并特别为后世的伊斯兰设计者所追求。伊斯兰设计者懂得如何使观赏者的脑子忙个不停，而又不使丰富多彩的图案失于混乱[图166]。一些哥特式窗花格图案也有同样的效果。这些图案能在我们的眼前分散，然后又重新组合，正如彼得·迈耶[PeterMeyer]画的图形所显示的那样[图167]。下文还将讨论其他装饰风格中的一些造成多义性的手段，这些手段将使我们看到，决定图案外形的是我们对意义的寻求和对秩序的寻求，而不是数学家们描述的结构。

这里，我们得再次回到柏拉图以及他对几何关系的客观存在的信仰。柏拉图认为，未被肉体模糊的灵魂可以在一瞬间把握所有的几何关系，他把这种能力归于神和高级的智性[Intelligences]。柏拉图的这种玄学思想形成了一个很久远的传统。我们被告知神不需要靠长期多次的知觉，而是凭直觉立即理解全部真理。可以这样说：这些神可以从各种现存的相互关系来看图形，而我们人类却只能靠有限的智力逐步认识这些图形。但是，话又说回来，我们的这种局限性并非不利，反而有益，因为那些一下子就完全理解整个图案的高级智性不可能像我们人类那样享受到图案中的雅趣和美。做人毕竟也有做人的好处。
