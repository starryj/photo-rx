# structure-read — 画面骨架读取

> 用途：把一张（或一组）照片还原成可数的结构元素与可判的关系，回答「这张照片靠什么立住、哪里散、动一改会怎样」。不评内容好坏，不做色彩诊断（那是 color-decision），不打分（那是 frame-critique 的分子之一）。

## R — 原文 (Reading)

> 从眼前的景象中捕捉到潜在的不同凡响的画面，然后将各种视觉元素组织成引人入胜的构图，一直是摄影的关键技能。
> ——弗里曼《摄影师的视界》p003

> 无须多言的是，任何场景和视角都不存在理想的地平线位置。
> ——同上 p029

> 如果你能平衡一张照片，让注意力首先被一个预期的点吸引，然后提供一条线条来暗示某个方向的运动，那么你就已经为眼睛安排了一条路线。
> ——同上 p091

## I — 方法论骨架 (Interpretation)

**骨架不是「主体放哪」，而是一串可回答的问题链。**本书给出的顺序是：画幅 → 分割 → 元素 → 关系 → 纵深 → 引导。六段各自独立可判，且都可以用可数或可测的量描述。

1. **画幅先于一切。**画幅是第一个设计决定，之后所有元素都在它给的边界里被比较。横、竖、方、全景不是风格偏好，而是把不同的注意力路径强加给观者：水平格式贴合双眼视场而显得「正常」；正方形四边等长，故任何偏离都会立刻被察觉，也因此容易显得刻板；全景让眼睛一次只看一部分，观看起来更像真实扫视，于是延长了观看时间。**判断画幅是否合适，看它是帮你延长观看还是缩短观看。**
2. **分割是比例问题。**1:1、2:1、3:2 这类简单数字给出的是静态分割，眼睛很快结算完；黄金分割要求「小:大 = 大:整体」，其实质是小区域与大区域的关系和大区域与整体的关系相同，因此视觉上不结算完。**这里的纪律是：比例是事后分析，拍摄时不计算，但熟悉之后直觉会给得更准。**
3. **元素只有三种基本形状，其余都是变体。**点、线、（矩形/三角形/圆形）面之间可以互相降级：一排点暗示一条线，几条线确定一个形状，一个面缩小到一定程度就只承担「点」的功能。**因此分析时不必争论它是点还是小物体，只需问它此刻在承担哪一级功能。**
4. **关系只有两条：平衡与对比。**对比负责制造差异，平衡负责让差异站得住。二者都是力的分配，而非美学立场。本书最锋利的一句是：眼睛追求和谐是事实，但**这不是一条构图规则**——功效不等于规则。
5. **平衡的判据不是「稳」，而是「值不值得花力气」。**观者的兴趣与他必须付出的努力成正比；平衡若太完美，眼睛无事可做。所以失衡、张力、轻微不适在这里不是错误，而是可调的量——前提是你能说出它在换什么。
6. **节奏与图案都建立在重复上，但方向相反。**节奏关涉方向：只有每个节拍都在推进眼睛，节奏才成立；图案关涉范围：眼睛在图案里四处漫游，故它是静态的。**一张照片看起来「热闹但没劲」，多半是把图案当成了节奏。**
7. **纵深靠知觉机制，不靠「近大远小」的口号。**大小恒常让大脑同时接受「显得小」与「实际大」；选择性聚焦靠两个触发点——注意力被吸向信息密度最高的清晰区，以及覆盖其上的失焦层被读作在前。因此失焦不是瑕疵，是一种排序手段。
8. **引导由三件东西完成：向量、视线、焦点。**向量是为眼睛安排路线（先给预期点，再给方向线）；视线是最强的隐含线，人脸看向哪里，眼睛就跟着去哪里；焦点是硬约束——**清晰度几乎是无可置疑的标准，所以落在焦点上的任何事物都会成为关注点**，这一点无法靠构图抵消。

**跨书硬约束（来自本包已裁决的对抗，运行时不重复争论）：**
- 和谐不是目标，只是众多关系之一（K1，按意图分岔）。
- 构图规则是条件判词，跨出条件即无依据（K5，每条判词必须挂失效条件）。
- 数值以脚本为准、色相以眼睛为准（K7，模型描述不得冒充测量）。

## A1 — 应用示例 (Application Example)

### 示例 1: 幼儿园（同一场景五次改位置，五次都在改骨架）

原书 p157–p158 的完整迭代，是本书唯一把「取景—判断—再取景」走满的案例。

- **第一次**：站立拍全景，孩子、老师、桌子、后面的瑞士小木屋式游戏屋全在画面里。作者的评语是「足够清楚、可接受，可作为改进的起点」。
- **第二次**：绕桌子走，找最强视点。壁画成了替代游戏屋的兴趣点，但「后脑勺太多」，且会把左边光秃的木墙包括进来，看不到足够的绘画活动。
- **第三次**：靠近壁画、在桌子另一边尝试。彩虹图案出现了，但另一组孩子拍不进画面。
- **第四次**：视点合理了——从前景男孩到其他孩子再到小木屋有很好的深度感。仍有改善空间。
- **第五次**：**降低相机位置**。两个理由：与孩子们同高提高参与度；展示更多彩虹图案并使构图更有动态（同一支广角镜头）。
- **定局**：男孩抬头、转身、眼神交流。作者点明「面孔总是具有很强的视觉分量」；动态主要来自桌子的曲线，彩虹色与广角变形加强它，脸、黄色盒子、蓝色窗户是三个停顿点，视线被引导后漫游细节但总会返回男孩脸上。

**从这个案例能抽出的三条可迁移判断**：①「足够清楚」是可接受的起点，不是终点；②每次改动只动一个变量（视点位置、然后机位高度），否则无法归因；③最后定局靠的是内容事件（眼神），不是构图技巧——技巧的作用是把那个时刻接住。

### 示例 2: 风车（六步，全部在动视点与机位高度）

原书 p169 用 20mm 在同一主体上做了六次取景：中距离排除环境得高对比蓝白（对称居中但「未能平衡两个云层区域」，放低处露太多天空，只部分成功）→ 更贴近使风车占更多画幅并偏离中心、视点右移让它只占云之间的空间 → 移到正前方，靠近后云层出画但揭示基座曲线变形，与上方三角结构形成悦目对比 → **相机大幅降低位置**，风车放较高并偏一角（广角增强深度的典型用法，景深允许时展示尽可能多的前景）→ 同位置倾斜相机、地平线降低露出天空与树木 → 位置再改进使前景细节更多更突出。

**可迁移点**：六步里没有一步是在改相机参数，全部是「站哪里、镜头朝哪、机身多高」。这就是 structure-read 的操作域。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 手里有一张已经拍完的照片，说不出哪里不对，但感觉「散」「挤」「平」「空」。
2. 拍摄前要看现场：该站哪、机位多高、横还是竖、主体放哪。
3. 想知道某条构图说法（三分法、黄金分割、地平线别压中线）在自己的这张照片上到底成不成立。
4. 一组照片要排序或配对，需要判断它们的结构是否重复、能否互撑。
5. 剪裁犹豫：裁掉之后骨架是变强还是断掉。

### 语言信号（中英双写）

- 中文：「这张照片看着有点乱 / 散 / 挤 / 平 / 空」「主体该放哪」「横的还是竖的」「地平线放哪」「三分法是不是必须」「裁到哪合适」「这张靠什么立住的」「画面怎么分块」「视线往哪跑」
- English: "what's wrong with this composition", "where should the subject go", "should I shoot this horizontal or vertical", "where do I put the horizon", "is the rule of thirds required here", "where should I crop", "what holds this frame together", "where does the eye go"

### 与相邻 skill 的区分

- **color-decision**：颜色主导时走那边。判据是「把这张转成黑白，画面还立不立」——立得住、问题在色彩关系 → color-decision；转黑白就塌、问题在骨头 → 本卡。
- **frame-critique**：那是打分的入口（五维、总—分—总、出报告页）。本卡只产出结构判断，分数由 frame-critique 汇总。
- **capture-decisions**：那是「按快门前要拍板的清单」（画幅/镜头/感光/光线/时间/视角/快门）。本卡是「已经决定了要看现场怎么组织」。
- **sequence-edit**：那是一组照片的编排与顺序。本卡处理单张骨架；多张之间的结构重复交给 sequence-edit。
- **shoot-plan**：那是光与时段的前期计划。本卡不判断光质，只说「这个位置在这个光向下骨架怎样」。

## E — 可执行步骤 (Execution)

**输入契约（缺一项就先问，不得猜）**
- 一张或几张图（路径或附件）＋ 一句话：你想解决的是「拍之前的现场」还是「拍完之后的诊断」。
- 画幅（若能读出像素就不用问）；主体是什么（用户指定，不由我判定）。
- 若在拍之前：可用机位范围、可用焦距。

**输出契约**
- 一条主导结构判断（一句话，含判据与量）。
- 3–5 条分项：画幅／分割／元素层级／平衡与对比／纵深／引导，每项给「成立／勉强／不成立」并给判据。
- 2–3 条可执行的改动，按代价排序（改机位 < 改焦距 < 改时刻 < 改主体）。
- 每条判词必须挂失效条件；数值标注来源（脚本测量／人眼判断）。

1. **定画幅与观看方式。**读出宽高比；判断这个画幅是在延长还是缩短观看（全景/长边强调 vs 正方形/居中）。
   完成标准：能说出「这个画幅让眼睛先做什么」。
   判停点：若画幅是用户唯一不能改的约束（如手机竖拍社交发布），跳过此步，直接进入第 2 步。

2. **数分割。**画面上有几条主导线（水平、垂直、斜、曲）；它们把画面切成几块；分割比例是简单数字（静态）还是非简单（不结算完）。
   完成标准：报出块数与比例，并判断分割是静态还是动态。
   判停点：若画面没有主导线（纯面、纯雾、纯抽象），写「无线性分割」，进入第 3 步。

3. **把元素降到点/线/面。**每个显著元素此刻在承担哪一级功能；有几个「点」（承担聚焦功能的最小显著物）；有几条隐含线（两点之间、视线、向量）。
   完成标准：给出「N 个点 + M 条隐含线 + K 个形状」这样的可数描述。
   判停点：若点数 > 7，不逐个分析，改判「是否已成图案」并转入第 5 步。

4. **判平衡与对比。**对比在哪（明暗/大小/形状/疏密）；平衡靠什么维持（对称、杠杆、色调配重）；是否存在「过于完美」的平衡。
   完成标准：说出对比轴与配重点，并给出「平衡过稳／刚好／失衡但有意」三选一。
   判停点：若用户的目标是「要张力」，此处不做纠正，只标注张力来源与代价。

5. **判节奏与图案。**重复单元是什么；重复是在推进方向（节奏）还是在铺满范围（图案）；有无一个不规则物打断。
   完成标准：给出「节奏／图案／两者混杂」的判定与一句理由。
   判停点：若画面无重复单元，写「无节奏结构」，不得硬凑。

6. **判纵深与引导。**纵深靠哪几种手段（重叠／大小／虚实／色彩／透视／框中框）；引导靠向量、视线还是焦点；焦点落在哪里。
   完成标准：列出纵深手段（至少一项）与引导三件套各自的落点。
   判停点：若焦点不在主体上，直接指出——「清晰度是硬约束，落在焦点上的任何事物都会成为关注点」，这条不能靠构图抵消。

7. **收束成一条判断 + 2–3 条改动。**判断必须能回答「这张靠什么立住」；改动按代价排序，并给每条的失效条件。
   完成标准：判断句 ≤ 40 字；改动 ≤ 3 条；每条带判停点。
   判停点：若说不出「靠什么立住」，就写「结构未成立」，不要用形容词补缝。

**不自行推导新数值**：本书给出的量只有黄金比例 1.618、简单比例 1:1/2:1/3:2、歌德亮度值（归 color-decision）。除此之外的位置、角度、面积一律用脚本测（measure_general.py），不得凭感觉报数。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 纯色彩问题（色偏、互补面积、白平衡）：转 color-decision。
- 用户要一个综合分数或报告页：转 frame-critique。
- 一组照片的顺序与配对：转 sequence-edit。
- 需要判断光质（硬/软、色温、时段）：转 shoot-plan。
- 内容本身是废墟、灾难、新闻事件：先读内容，结构判断必须让位于「这张该不该拍」。

### 作者在书中警告的失败模式
- **把构图技巧当规则用**（p131：「功效并不是规则」）——效果可预期只说明对多数人有效，不说明更好。
- **把动态张力当万能**（p045）——它缺乏持久力，效果转瞬即逝，频繁使用会做作。
- **把裁剪当设计的万能药**（p021）——裁剪打断制作过程，多数图像得益于视觉连续性。
- **为不同而不同**（p135）——温诺格兰德「如果我在取景器里看到一张熟悉的照片，我会做点事情来改变它」，作者判为「很弱的目的和理由」。
- **在平衡上追求完美**（p043）——平衡太完美，眼睛无事可做，观者不会停留。
- **把图案当节奏**（p051）——图案关涉范围而非方向，堆满重复单元不等于有节奏。

### 作者的盲点·时代局限
- 本书的判据建立在**纸质观看**上：全景之所以延长观看，前提是「照片够大、观看距离够近」。手机屏幕上的全景反而缩短观看，此条件今天大多不成立。
- **画面分割一节的几何方法继承了文艺复兴—包豪斯的教学传统**，其有效性靠教学反复验证，而非实验证据；本书也未给出「哪种比例在哪类题材上更有效」的数据。
- 书里的**器材前提是单反 + 定焦 + 三脚架**；手机的多摄切换与计算摄影（合成景深、多帧对齐）会改变「焦距决定透视」这条推导的边界。
- 本章几乎不谈**动态范围与曝光对结构的影响**，那部分留给第4章与《光线与用光》。
- 作者反复用「眼睛会……」解释机制，但引用的是格式塔与 1960–70 年代的知觉研究；后续视觉科学的结论有修正，遇到硬机制问题应标注「此处为原书解释」。

### 容易混淆的邻近方法论
- **三分法 vs 黄金分割**：三分法是 1/3 的整数近似（静态分割的一类）；黄金分割是 1:1.618 的连续比例。二者不是同一件事，混用会让判词失去依据。
- **视觉线 vs 实有线**：隐含线由两点或视线构成，没有实体；两者的张力不同，实有线先于隐含线。
- **图案 vs 节奏**：见上，方向 vs 范围。
- **动态张力 vs 失衡**：张力是有意的、可说出在换什么的；失衡是说不出来的。
- **「没有理想的地平线位置」 vs 「地平线别压中线」**：前者是原则（位置由内容决定），后者是经验（压中线易把画面切平）。前者包含后者，反之不成立。
